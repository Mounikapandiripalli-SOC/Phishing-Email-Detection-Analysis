# Phishing Email Detection & Analysis

# Project Overview

A hands-on SOC investigation project focused on detecting and analyzing phishing-style emails using email header analysis, authentication validation, IOC extraction, threat intelligence, social-engineering analysis, and evidence correlation.

The project was performed in a controlled lab environment using test email accounts and controlled test content.

# Objectives

- Analyze raw email headers and email content
- Validate SPF, DKIM, and DMARC authentication results
- Extract Indicators of Compromise (IOCs)
- Investigate source IP reputation using threat intelligence
- Identify phishing and social-engineering indicators
- Correlate technical and behavioral evidence
- Perform risk-based email assessment
- Produce an evidence-based final verdict

# Investigation Workflow

Email Collection
→ Raw Email Analysis
→ Header Analysis
→ SPF/DKIM/DMARC Validation
→ IOC Extraction
→ Threat Intelligence Investigation
→ Social-Engineering Analysis
→ Evidence Correlation
→ Risk Assessment
→ Final Verdict

# Project 1 — Account Verification Phishing Email

Analyzed a controlled phishing-style email containing an urgent account verification request.

Investigation included:

- Email header analysis
- SPF, DKIM and DMARC validation
- Source IP identification
- IOC extraction
- IP reputation investigation
- URL assessment
- Social-engineering analysis
- Evidence correlation
- Final security assessment

# Project 2 — Password Reset / Security Alert Phishing Email

Analyzed a second controlled phishing-style email using a password-reset and account-security pretext.

Investigation included:

- Email content analysis
- Phishing indicator identification
- Social-engineering analysis
- URL analysis
- IOC identification
- Technical evidence correlation
- Risk assessment
- Final security assessment
